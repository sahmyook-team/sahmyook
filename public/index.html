어떻게 만들어지나요?

아이디어 한 줄이 서비스가 되기까지

  1. 아이디어 적기

    Google 문서 sahm_all에 원하는 기능을 적습니다.

  2. 작업 지시로 정리

    내용이 GitHub 저장소의 sahm.txt로 옮겨집니다.

  3. AI가 만들고 사람이 확인

    AI가 코드를 만들어 PR을 올리고, 사람이 검토·승인합니다.

  4. 서비스에 반영

    승인된 내용이 이 페이지(Google Cloud Run)에 반영됩니다.

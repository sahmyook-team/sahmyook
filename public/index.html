참여 방법

참여자가 Google 문서 sahm_all에 원하는 기능을 적으면 반영이 됩니다.

sahm_all 문서 열기 →

어떻게 만들어지나요?

  1. 참여자가 Google 문서 sahm_all에 원하는 기능을 적습니다.
  2. 내용이 GitHub 저장소의 sahm.txt로 옮겨집니다.
  3. AI가 코드를 만들어 PR을 올리고, 사람이 검토·승인합니다.
  4. 승인된 내용이 이 페이지(Google Cloud Run)에 반영됩니다.

바로가기

결재 폴더검토할 결재 파일(zip·PDF·HWP·엑셀 등)을 여기에 올립니다 보고서 폴더검토가 끝나면 보고서가 여기에 생깁니다

검토 실행

결재 폴더에 올린 파일을 결재 검토 원칙대로 지금 바로 검토합니다. 검토가 끝난 파일은 결재 폴더에서 지워지고, 보고서는 보고서 폴더에 생깁니다. 보통 5~10분 걸립니다.

진행 상황

검토가 어디까지 왔는지 보여 줍니다(건수·시각만 표시, 결재 내용은 표시하지 않음). 검토 중에는 10초마다 새로 고칩니다.

불러오는 중…

쓰는 방법

  1. 전자결재에서 내려받은 zip 파일(1건 = zip 1개)이나 낱개 파일(예산서 등 PDF·HWP·HWPX·엑셀·워드·이미지, 파일 1개 = 1건)을 결재 폴더에 그대로 올립니다.
  2. 예산 서류는 결재 폴더 안 규정 폴더의 편성지침과 대조해 서식 오류·편성지침 오류를 확인합니다. 편성지침은 규정 폴더에 올려 두세요(규정 폴더의 파일은 지워지지 않습니다).
  3. [검토 실행]을 누르면 바로 검토가 시작됩니다(누르지 않아도 매시 14분에 자동으로 확인합니다). 개인정보(주민번호·면허번호 등)를 먼저 가린 뒤 AI가 결재 검토 규칙대로 확인합니다.
  4. 검토가 끝나면 보고서 폴더에 보고서가 생기고, 검토한 파일은 결재 폴더에서 지워집니다.

결재 폴더와 보고서 폴더는 비공개입니다. 폴더 권한이 있는 사람만 열 수 있습니다. 보고서는 90일 동안 보관됩니다.
